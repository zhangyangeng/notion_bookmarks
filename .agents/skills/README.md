# 技能索引

本目录存放**可复用的实践技能**（`SKILL.md` + 配套脚本），按需读取，不自动载入上下文。

与 `rules/` 的区别：

- `rules/` 是**规范** —— 约定"应该怎样"，长期稳定
- `skills/` 是**操作手册** —— 记录"具体怎么做"，含可执行的步骤与示例

## 技能列表

> 技能按需登记。当某个多步流程需要被重复执行时，在此补充条目并附操作说明。

## 登记方式

```
.agents/skills/<技能名>/
├── SKILL.md          # 适用场景、前置条件、步骤、验证方式
└── <脚本或模板>       # 可选
```

登记后在上方「技能列表」中补一行，说明**何时使用**与**入口文件**。
