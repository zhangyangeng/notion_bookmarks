选型路径

初版三选给的是三个跨色系方向 —— 琥珀·靛（暖赭 + 深靛）、墨绿·米白、灰·淡蓝，用于回答「整站该是什么气质」。
选定 墨绿·米白 后，在绿系内出四档微调 —— 旧墨水绿、植物标本绿、苔灰绿、青铜绿，用于回答「绿到什么程度」。
最终采用 旧墨水绿，落地为 --primary: 63 92 74（深色 147 184 155），即本页默认配色（按钮带 ✓）。
