## 二、设计方向

**总纲**：浅色琥珀 + 深色靛蓝的双调色 + 雾面玻璃（blur 16–24 + saturate 180）+ 高密度信息卡片（2–3 列、宽卡、3–5 行描述 + 标签底栏）。

气质：不装「科技感」，装「夜读感」——像翻一本深米色页 + 黑墨字的私人笔记。

### 2.1 配色（替换 `globals.css` 的 `:root` / `.dark` 变量，只动值不动结构）

浅色默认：暖白底 `oklch(0.985 0.012 80)`、深靛文字 `oklch(0.22 0.04 280)`、琥珀主色 `oklch(0.45 0.13 25)`。
深色：深靛底 `oklch(0.18 0.02 280)`、暖白文字、提亮琥珀主色 `oklch(0.75 0.13 65)`。

（完整变量表见正文对话；核心是一冷一暖，文字偏冷易读、底色偏暖放松，避开 AI 风紫渐变。）

### 2.2 背景层（让玻璃有东西可透）

`body` 加超低频彩色径向光斑（`background-attachment: fixed`，不参与滚动合成，几乎零性能损耗）。玻璃只用在侧栏/搜索/命令面板/详情浮层 4 处，卡片网格不用。

### 2.3 卡片（头号痛点：描述看得见）

| 维度 | 现在 | 改后 |
| :--- | :--- | :--- |
| 列数 | `sm:2 md:3 lg:4 xl:5` | `sm:1 md:2 lg:3 xl:3 2xl:4` |
| 方向 | 垂直堆叠 | 桌面横向（左图标右内容），手机纵向 |
| 图标 | 40×40 | 56×56 `rounded-2xl`，浅色用 `bg-muted` 不包边 |
| 标题 | `text-lg line-clamp-1` | `text-base font-semibold`，允许 2 行 |
| 描述 | `line-clamp-2` | `line-clamp-3`（约 84 字） |
| 标签 | 3 个 + "+N" | 2 个（推荐 + 分类色块） |
| 高度 | `h-full`（被 5 列压矮） | `min-h-[120px]` 明确高度 |
| 圆角 | `rounded-xl` | `rounded-2xl`（`--radius` 调 1rem） |
| 边框 | `border/50` | 浅色去边框靠阴影分层，深色 `border-white/8` |
| hover | `-translate-y-0.5` | `-translate-y-1 + shadow-xl + scale-[1.01]` |

### 2.4 侧栏（痛点 5）

- 选中态改「左侧 3px 琥珀竖条 + 浅琥珀背景」，不再整块变黑；
- 一级始终展开当前选中组，其他折叠（`expandedCategoryId` 跟随选中）；
- 每个分类加数字 badge（不用展开就知道这组多大）；
- 整侧栏玻璃化，与底部 footer 分层；
- 移动端顶栏只留 logo + 主题 + 搜索按钮，分类走抽屉。

### 2.5 卡片点击展详情（痛点 4，只留 UI 不做后端）

- 卡片右上角小箭头按钮（`hover:opacity-100 opacity-0`），区别于外链主操作；
- 点击就地展开（原生 `<details>` 或 Radix Collapsible），展示 `review`；
- `review` 为空时显示斜体灰字「点评待补」占位；
- 展开态用 `useState` 维护 `Set<id>`，不持久化、不编辑、不做模态框。

### 2.6 动画（痛点 3，克制）

只动三处：卡片进场错位淡入（`animate-fade-in` + CSS `--i` 延迟，`IntersectionObserver` 触发视口外部分）、卡片 hover、侧栏展开高度过渡（`grid-template-rows: 0fr→1fr`）。不引入 framer-motion（已删，CSS 够用）。

### 2.7 圆润 / 不线条化（痛点 6）

`--radius` 提 1rem；卡片浅色去边框靠阴影；交互元素 `rounded-xl` 起；选中态改圆角背景 + 左侧竖条。

## 七、调研技术要点备忘

### 液态玻璃（Web 实现）

- `backdrop-filter: blur() saturate()` 是 Baseline 2024，主流全支持（Safari 需 `-webkit-` 前缀，Tailwind 已自动加）。
- WWDC 2025 真液态玻璃 = 叠加 SVG `feDisplacementMap`（折射）+ `feSpecularLighting`（镜面高光），Chrome 76+/Safari 16.4+/Firefox 103+。
- **玻璃只有在非平背景上才看得出** → 需给页面配彩色光斑/渐变底图。
- **性能**：多卡片同时 backdrop-blur 显著掉帧 → 只用于少量大面积（侧栏/面板），卡片网格不用。
- 配方参考：`background: rgba(255,255,255,0.15)` + `backdrop-filter: blur(20px) saturate(180%)` + `border: 1px solid rgba(255,255,255,0.2)` + 柔和阴影。

### 动画选型（Tailwind vs framer-motion）

- 简单 hover/focus/循环动画 → Tailwind CSS（零 JS）。
- 依赖 React state / 生命周期 / 复杂编排 / exit 动画 → framer-motion。
- 本项目三处动画都可用纯 CSS 表达，无需重装 framer-motion。

### 卡片展开（max-height / grid-rows 过渡）

- 用 `grid-template-rows: 0fr→1fr` 过渡，无需 JS、自适应内容高度，优于 `max-h-0→max-h-96`（后者需写死上限）。

### 库的体积参考

- Radix UI primitives ≈ 40KB gzip（按需更小，3–5KB/组件）；shadcn/ui 零运行时（复制进代码）；framer-motion 需重新引入（约 30KB+）。
